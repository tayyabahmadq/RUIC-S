1. WHAT I BUILT
- CLI & surface plugin for COMMONS: registers five /opus commands (run, status, crew, report, config), renders a live dashboard driven entirely by bus events, provides human formatting (tokens, durations, ANSI severities), and ships a graceful Ctrl-C abort that emits run.failed with reason 'aborted'.
- Provides pure render + format helpers that reconstruct dashboard state from a full event replay (DELTA) for mid-run opens.
- Provides a working stubs.ts with event bus, commons client, transport, locks, task queue, working set, artifact store, task bus for standalone builds.
- Throws CommonsError { code, folder: 'folder-10', detail } on every failure.
- Standalone (TypeScript strict, Node 20+, zod dep) passes `npm run build` and `npm test` with 13 smoke tests covering all public exports.

2. FILE MAP
- package.json — manifest, scripts (build/typecheck/test/smoke/verify), deps (zod + dev deps).

8. INTEGRATION NOTES
- Dashboard does not throttle re-render; high event rates may produce many renders. Integrator may add debounce.
- Commands assume no args; integrator may accept arguments if extended.
- abort.ts's registerAbort currently only registers one handler per process; calling again is a no-op. Re-running a new run requires a fresh process.
- Task/finding IDs and disk state come from other parts via events; folder-10 does not write to COMMONS.
- The RUN STANDALONE banner printed to stderr on abort is a placeholder; DELTA pointer is a plain message.
- registry integration gap: healthCheck shape not typed (OPEN: add a Registry interface in types.ts under a follow-up).
- Node 20+ required; npm test relies on node:test.
