# OPUS//DECK — FOLDER-01 INTEGRATION CONTRACT

Machine-readable integration document for the Opus//DECK multi-model orchestration plugin.
Authoritative source for folder-01. Parallel-build contract: parts/folder-01 owns scaffold, configuration, event bus and canonical paths.

## 1. WHAT I BUILT

- folder-01 implements the foundation layer of Opus//DECK: strict TypeScript configuration validation, a typed in-process event bus, and the canonical COMMONS path constants.
- `initOpusDeck(config)` validates an `OpusDeckConfig` with zod, resolves defaults (digestTokens=2000, promptTokens=6000), absolutizes `memoryDir`/`outputDir`, creates both directories, and returns an `OpusDeckRuntime` containing the event bus, resolved config, version and shutdown function.
- The event bus (`EventBusImpl`) implements typed `on`, `once` and `emit` for the twelve contract events and forwards every event to an `EventSink` (default: `ConsoleEventSink`, a working stub).
- The canonical COMMONS paths (`BRIEF_MD`, `DECISIONS_LOG`, `STATE_DIGEST`, `STATE_PRESENCE`, `STATE_TASKS`, `WORKSPACE_DIR`, `DELTA_DIR`, `ARCHIVE_DIR`) are exported as absolute path constants derived from `OPUS_DECK_COMMONS_DIR` or `<cwd>/COMMONS`.
- Every failure path throws `CommonsError` with `folder: 'folder-01'`.

export type EventPayloads = {
  'run.started': RunStartedPayload
  'task.claimed': TaskClaimedPayload
  'task.completed': TaskCompletedPayload
  'memory.written': MemoryWrittenPayload
  'finding.raised': FindingRaisedPayload
  'finding.resolved': FindingResolvedPayload
  'compaction.requested': CompactionRequestedPayload
  'compaction.started': CompactionStartedPayload
  'compaction.done': CompactionDonePayload
  'crew.sync': CrewSyncPayload
  'run.completed': RunCompletedPayload
  'run.failed': RunFailedPayload
}

export interface EventBus {
  on(event: EventName, handler: (payload: EventPayloads[EventName]) => void): void
  once(event: EventName, handler: (payload: EventPayloads[EventName]) => void): void
  emit(event: EventName, payload: unknown): void
}

export interface EventSink {
  write(event: EventName, payload: EventPayloads[EventName]): void
}

export interface OpusDeckRuntime {
  bus: EventBus
  config: ResolvedConfig
  version: string
  shutdown(): Promise<void>
}

## 4. EXPECTS FROM OTHERS

- Exact interface stubbed against: `EventSink` (defined in folder-01 `src/types.ts`), default implementation `ConsoleEventSink` provided in folder-01 `src/stubs.ts` so folder-01 builds standalone.

- The integrator does not need any other interface from folder-01; folder-01 defines the foundation contracts others consume.

## 5. PROVIDES TO OTHERS

- `initOpusDeck`, `EventBusImpl`, `resolveOpusDeckConfig`, `CommonsError`, `ConsoleEventSink`, the path constants and all types listed in section 3.
- Consumers should import from the package root (the barrel in `src/index.ts`) and address all COMMONS memory through the exported path constants instead of hardcoding paths.
- Other folders should throw `CommonsError` for all failures and emit the twelve contract events through the `EventBus` so the security gate and compactor can subscribe.

Canonical COMMONS path constants (nine):

All nine canonical COMMONS path constants are composed absolute paths built with `path.join()` from the COMMONS root and bare segment names (no trailing slashes) via `src/paths.ts`:

- `BRIEF_MD` = `path.join(COMMONS_ROOT, 'BRIEF.md')`
- `DECISIONS_LOG` = `path.join(COMMONS_ROOT, 'DECISIONS.log')`
- `STATE_DIGEST` = `path.join(COMMONS_ROOT, 'STATE', 'digest.md')`
- `STATE_PRESENCE` = `path.join(COMMONS_ROOT, 'STATE', 'presence.json')`
- `STATE_TASKS` = `path.join(COMMONS_ROOT, 'STATE', 'tasks.json')`
- `WORKSPACE_DIR` = `path.join(COMMONS_ROOT, 'WORKSPACE')`
- `DELTA_DIR` = `path.join(COMMONS_ROOT, 'DELTA')`
- `ARCHIVE_DIR` = `path.join(COMMONS_ROOT, 'ARCHIVE')`
- `TXN_LOG` = `path.join(COMMONS_ROOT, 'DELTA', 'txn.jsonl')`

Where `COMMONS_ROOT = path.resolve(process.env.OPUS_DECK_COMMONS_DIR ?? path.resolve(process.cwd(), 'COMMONS'))`.

Segment values (bare, no trailing slash): `BRIEF.md`, `DECISIONS.log`, `STATE`, `digest.md`, `presence.json`, `tasks.json`, `WORKSPACE`, `DELTA`, `ARCHIVE`, `txn.jsonl`. Directory segments (`WORKSPACE`, `DELTA`, `ARCHIVE`, `STATE`) carry no trailing slash.

## 8. INTEGRATION NOTES

- Assumptions when ambiguous (simplest interpretation chosen and recorded here):
  - `budgets` is optional on the input config; when omitted, defaults `digestTokens=2000` and `promptTokens=6000` are filled. `ResolvedConfig.budgets` always exposes both numbers.
  - `goalState` entries must be non-empty strings; the array requires at least one criterion.
  - `ModelRef.provider` accepts only `'openai-compatible' | 'anthropic' | 'custom'`; `speedClass` accepts only `'fast' | 'standard' | 'heavy'` and is optional.
  - `contextWindowTokens` must be a positive integer.
  - Canonical paths are computed at module load from `OPUS_DECK_COMMONS_DIR` (when set) or `<cwd>/COMMONS`. `initOpusDeck` treats `config.memoryDir` as authoritative for runtime writes; the integrator must keep the env var and the config value pointing at the same directory.
  - The event bus is synchronous; handlers run in registration order; `once` handlers self-remove after the first invocation.
  - `emit` forwards to the `EventSink` even when no handlers are registered for the event.
  - `shutdown()` returns an already-resolved promise and is idempotent.
  - The runtime version is read from `package.json` at runtime and falls back to `0.0.0`.
  - Output is CommonJS; the package has no `"type": "module"`.
- Gaps:
  - `initOpusDeck` does not emit `run.started`; lifecycle orchestration (run creation, claiming, completion) belongs to later folders.
  - `initOpusDeck` performs no memory writes, task assignment or security audit; those belong to later folders.
  - The `OpusDeckRuntime` shape is fixed by the build contract; there is no options parameter for injecting a custom `EventSink` into `initOpusDeck`. Replacements happen via the stub seam in `src/stubs.ts` + `src/bootstrap.ts`.
  - Event names are a closed contract and are not versioned.
- Decisions for the integrator:
  - Single error on invalid config: one `CommonsError` with code `config.invalid` whose message enumerates every invalid field at once (`field: reason; ...`), aggregated from all zod issues.
  - `EventBus` handler parameter is typed as the union of the twelve payload types via `EventPayloads[EventName]`; handlers narrow with ordinary TypeScript checks.
  - The test command is the explicit file `node --test dist/smoke.test.js` after compilation, to guarantee a deterministic, version-portable test invocation.

## 9. DO NOT CHANGE

Invariants that must survive integration. Violating any of these fails the shared contract.

- The signature `initOpusDeck(config: OpusDeckConfig): OpusDeckRuntime` must remain the only public bootstrap entry point and must keep accepting exactly one parameter.
- `OpusDeckRuntime` must keep the fields `bus: EventBus`, `config: ResolvedConfig`, `version: string`, `shutdown(): Promise<void>`.
- `CommonsError` must keep the shape: extends `Error`, has `code: string`, `folder: 'folder-01'`, optional `detail?: string`.
- The closed set of event names and payload types in `EventPayloads` must not be renamed, removed or re-typed without updating every folder.
- The `EventBus` interface (`on`, `once`, `emit`) and the `EventSink` interface (`write`) must not change shape.
- `EventBusImpl` must continue to implement `EventBus` and forward to `EventSink.write`.
- The nine canonical COMMONS path constants and their file/dir names must not change: `BRIEF.md`, `DECISIONS.log`, `STATE/digest.md`, `STATE/presence.json`, `STATE/tasks.json`, `WORKSPACE`, `DELTA`, `ARCHIVE`, `DELTA/txn.jsonl`. Directory segments carry no trailing slash.
- Budget defaults must remain `digestTokens = 2000` and `promptTokens = 6000`; both must be exposed on `ResolvedConfig.budgets`.
- Validation invariants must remain: `goalState` minimum length 1, `crew.engineers` minimum length 1, `crew.security` minimum length 2.
- Runtime dependencies must remain limited to `zod`; no framework, no runtime dependency additions.
- TypeScript strict mode, kebab-case file names, `node:test` smoke tests, and no-`any` policy must be preserved.
